# 🍇 Clasificador de Uvas

Aplicación web que clasifica uvas usando un modelo de **Teachable Machine**.

## Clases
- Uvas Italia
- Uvas Quebranta

## Cómo usar
1. Abre `index.html` en el navegador
2. Haz clic en **Iniciar cámara**
3. Apunta la cámara a las uvas y verás la predicción en tiempo real

## Modelo
Entrenado con [Teachable Machine](https://teachablemachine.withgoogle.com/models/taJCbfxNC/)

## Tecnologías
- TensorFlow.js
- Teachable Machine Image Library
- HTML / CSS / JavaScript
