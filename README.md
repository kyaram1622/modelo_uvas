# Clasificador de Uvas

Aplicación web que clasifica uvas usando un modelo de Teachable Machine.

## Clases
- Uvas Italia
- Uvas Quebranta

## Modelo
Entrenado con [Teachable Machine](https://teachablemachine.withgoogle.com/models/taJCbfxNC/)

## Tecnologías
- TensorFlow.js
- Teachable Machine Image Library
- HTML / CSS / JavaScript
